# 0. 가장 중요한 수정

기존 사양서의 가장 큰 문제는 로고의 색을
**마젠타 / 바이올렛 / 블루라는 서로 다른 요소처럼 분리해서 사용한 것**이다.

목회 AI 연구소 로고의 핵심은 색 자체가 아니라,

> **서로 다른 색과 면이 경계 없이 겹치고 스며들며 하나의 형태가 되는 것**

이다.

따라서 앞으로 모든 디자인에서 다음 원칙을 최우선으로 적용한다.

```text
분리된 색상 블록 X
경계가 강한 컬러 카드 X
마젠타 아이콘 + 블루 아이콘의 반복 X
각 요소마다 다른 브랜드색을 칠하는 방식 X

연속적인 색의 흐름 O
투명한 면의 겹침 O
부드러운 색 전이 O
하나의 시각 덩어리로 인식되는 구성 O
```

# 2. 로고 해석

## 2-1. 로고는 ‘세 가지 색의 조합’이 아니다

실제 로고는 다음과 같이 읽는다.

```text
Magenta
   ↓
Pink / Violet
   ↓
Blue
```

하지만 이 세 영역은 서로 독립된 컬러 블록이 아니다.

**투명한 면과 색이 중첩되면서 하나의 AI+Cross 형태를 만든다.**

따라서 로고의 시각적 특징은 다음과 같다.

- 외곽 실루엣은 형태를 인지할 수 있을 만큼 유지
- 내부 색 경계는 강하게 끊지 않음
- 마젠타와 블루 사이에 자연스러운 중간색 존재
- 일부 면은 반투명하게 겹쳐짐
- 색이 겹치는 지점에서 새로운 색이 만들어짐
- 선으로 외곽을 두르지 않음
- 강한 그림자 없음
- 전체적으로 하나의 덩어리처럼 인식

# 3. 로고 사용 절대 규칙

## 3-1. 원본 로고 우선

공식 디자인에서는 반드시
**승인된 원본 AI+Cross 로고 파일**을 사용한다.

### 금지
- 생성형 AI에게 로고를 다시 그리게 하지 않는다.
- 이미지 생성 프롬프트 안에서 로고를 재현하게 하지 않는다.
- 로고를 임의로 단순화하지 않는다.
- 로고의 A / I / Cross를 따로 떼어내지 않는다.
- 색을 임의로 변경하지 않는다.
- 새로운 워드마크를 임의 제작하지 않는다.

### 이미지 생성물에 로고가 필요할 경우

```text
1. 이미지 생성 단계에서는 로고 영역을 비워 둔다.
2. 생성 완료 후 실제 원본 로고 PNG/SVG를 별도 삽입한다.
3. 로고 주변 충분한 여백을 확보한다.
```

**AI가 그린 유사 로고는 공식 브랜드 자산으로 사용하지 않는다.**

# 4. 로고 컬러

실제 로고에서 확인되는 대표 색을 기준으로 한다.

| 역할 | HEX | 설명 |
|---|---|---|
| Magenta Core | `#EA48E1` | 시작점 |
| Pink Light | `#FA8AF9` | 밝은 투명층 |
| Soft Pink | `#F6BEFF` | 가장 부드러운 연결 |
| Violet Light | `#A8AEFE` | 핑크와 블루의 연결 |
| Blue Mid | `#6496FD` | 중간 블루 |
| Blue | `#1580FD` | 대표 기술 색 |
| Deep Blue | `#154FDF` | 가장 깊은 블루 |

## 중요한 원칙

이 색들을 **7개의 독립 색상처럼 사용하지 않는다.**

색상은 반드시 다음 중 하나로 사용한다.

1. 하나의 연속 그라디언트
2. 반투명 면의 중첩
3. 매우 제한된 단일 포인트
4. 흐릿한 빛 또는 배경의 색조

# 5. 공식 브랜드 그라디언트

## Primary Fusion Gradient

```css
linear-gradient(
  115deg,
  #EA48E1 0%,
  #FA8AF9 18%,
  #A8AEFE 48%,
  #6496FD 68%,
  #1580FD 84%,
  #154FDF 100%
)
```

## Soft Fusion Gradient

배경·라인·은은한 강조용.

```css
linear-gradient(
  115deg,
  rgba(234,72,225,.65) 0%,
  rgba(168,174,254,.55) 48%,
  rgba(21,128,253,.65) 100%
)
```

## 사용 원칙

- 그라디언트는 화면 전체를 덮지 않는다.
- 화면에서 **2~6% 정도의 시각적 포인트**로 사용한다.
- 그라디언트 끝점을 서로 끊어 보이게 하지 않는다.
- 단일 요소 안에서 자연스럽게 이어져야 한다.

# 6. 경계와 흐림의 원칙

## 6-1. 가장 중요한 시각 규칙

목회 AI 연구소의 컬러 요소에는
**“내부 경계가 명확하게 보이지 않는 것”**이 중요하다.

### 적용

```text
외곽 형태:
정돈됨

내부 컬러 경계:
부드러움

색 전환:
연속적

면의 중첩:
반투명

그림자:
거의 없음
```

## 6-2. Blur / Feather

1080~1350px 카드뉴스 기준:

- 컬러 하이라이트 blur: 12~28px
- 큰 배경 광원 blur: 40~90px
- 오브젝트 자체 blur: 사용하지 않음
- 텍스트 blur: 절대 금지

즉,
**디자인 전체를 흐리게 만드는 것이 아니라
색이 만나는 경계만 부드럽게 만든다.**

# 17. 그래픽 모티프

## 17-1. Soft Fusion Ribbon

로고의 중첩된 면을 확장한
반투명 리본 또는 얇은 면.

특징:

- Magenta → Violet → Blue
- 경계 없는 전이
- 10~35% opacity
- 텍스트 뒤를 가리지 않음
- 화면 한쪽에서 흐르듯 배치

## 17-2. Soft Light Field

페이지 가장자리나 여백에
아주 흐릿한 색광을 배치한다.

```text
Magenta haze
→ Violet overlap
→ Blue haze
```

## 17-3. Cross Intersection

`+`는 상징적으로 사용할 수 있으나
십자가를 별도의 장식 아이콘처럼 반복하지 않는다.
