## 단계 시작 방향성 제안
1. **실제 세미나 신청 유도 (추천·선택)**
2. 프로그램 소개 중심 정보형
3. 장기 교육 멤버십 유도형
4. 세미나 영상 사후 신청형
5. 사용자 정의(직접 입력)

**결정 기록:** 응답을 기다리지 않고, 이미 제공한 포스터·문구·디자인 사양서에 가장 부합하는 추천안을 가정하여 진행했습니다.

## 프로젝트 목적과 금지
- 목적: 10월 20일 온라인 세미나의 구글폼 신청 클릭을 증가시키는 구조를 설계한다.
- 안내문에서 확인한 문구: 반복 설명, 같은 질문, 자료/대화 관리, 목회와 실제 업무 적용.
- 전환을 위한 사실 없는 후기, 인증, 무료 문구, 좌석 마감, 할인, 실습 보장은 사용하지 않는다.
- 로고 원본이 없으므로 상표 모방 없이 일반 텍스트 '목회AI연구소' 사용.
- 디자인 팔레트는 제공된 공식 사양을 적용한 **추천안**으로, 최종 사용자 확인을 남긴다.

## 역할별 최초 검토
- 기획자: 문제 제기 → 구체적 내용 → 일정/주최 → 신청으로 연결.
- 카피라이터: '매번 처음부터 설명하시나요?'를 핵심 공감 문장으로 선정.
- 디자이너: 흰 여백, 네이비 텍스트, 브랜드 색은 하나의 낮은 비율 흐름으로 제한.
- 비판 검수자: 참가비 미확인·실제 실습 여부 미확인·접속 안내 불분명 사항을 열어 둔다.


## 실패 시나리오 및 대응
1. **가격과 접속 절차 미확인으로 신청을 망설임** → 신청폼 또는 주최 측의 확정 정보 확인 후 FAQ와 세부 안내를 업데이트합니다.
2. **사진·문구가 작은 화면에서 겹침** → 375px뿐 아니라 320px까지 화면 캡처와 넘침 검사를 반복합니다.
3. **신청폼 접근이나 링크 전달에 장애 발생** → 주최 측이 실제 모바일 기기에서 폼을 최종 확인하고 링크를 교체·안내합니다.
