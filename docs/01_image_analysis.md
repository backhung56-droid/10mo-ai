## 원본 및 사양서 간 차이
- 원본 포스터에는 색 리본의 면적이 상대적으로 크지만 공식 사양은 전체 약 2~5%의 연결된 포인트 사용을 지향합니다. 랜딩에서는 얇은 선과 낮은 채도의 발광 영역으로 절제합니다.
- 포스터는 제목 우선 구조지만 사이트에서는 문제 공감 카피를 H1으로 배치해 전환 동기를 강화합니다. 정확한 행사 제목은 눈에 보이는 별도 라벨로 유지합니다.
- 원본 사진 속 인물을 정확히 재사용하며, 이미지를 통째로 배경에 넣을 때 발생하는 중복 문자 노출을 막기 위해 인물용 이미지를 별도 준비합니다.

## 검수 관점
- 기획자: 제목과 행동이 바로 이어져야 함.
- 카피라이터: 출처에 없는 특별혜택·시연 보장 금지.
- 디자이너: 실제 강사 얼굴과 여백의 대비를 유지.
- 비판 검수자: 공식 로고가 없고, 포스터만으로 신청폼 설정을 알 수 없음.


## 실패 시나리오 및 대응
1. **가격과 접속 절차 미확인으로 신청을 망설임** → 신청폼 또는 주최 측의 확정 정보 확인 후 FAQ와 세부 안내를 업데이트합니다.
2. **사진·문구가 작은 화면에서 겹침** → 375px뿐 아니라 320px까지 화면 캡처와 넘침 검사를 반복합니다.
3. **신청폼 접근이나 링크 전달에 장애 발생** → 주최 측이 실제 모바일 기기에서 폼을 최종 확인하고 링크를 교체·안내합니다.
