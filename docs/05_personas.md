| 관망·비교형 | '다른 영상이나 강의와 뭐가 다른가요?' | 프로젝트에 집중된 범위를 이해 | 주제·강사·진행 방식 투명성 | 비용·세부 강의 계획 미확인 |

## 페르소나별 기능 요구
- 호감: 상단에서 세미나명 확인, 하단에서 3개 학습 주제 확인.
- 비판: 실제로 약속되지 않은 실습·인증·성과 문구 금지.
- 거부: 현재 작업에서 생기는 마찰을 3가지 구체 문장으로 표현.
- 신청: 첫 화면에 CTA, 상단/하단/모바일 고정 신청 동선.
- 관망: FAQ와 행사 개요를 분리하되, 확인되지 않은 질문은 별도 안내.


## 실패 시나리오 및 대응
1. **가격과 접속 절차 미확인으로 신청을 망설임** → 신청폼 또는 주최 측의 확정 정보 확인 후 FAQ와 세부 안내를 업데이트합니다.
2. **사진·문구가 작은 화면에서 겹침** → 375px뿐 아니라 320px까지 화면 캡처와 넘침 검사를 반복합니다.
3. **신청폼 접근이나 링크 전달에 장애 발생** → 주최 측이 실제 모바일 기기에서 폼을 최종 확인하고 링크를 교체·안내합니다.
