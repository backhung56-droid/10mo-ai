## 단계 시작 방향성 제안
1. **제공 포스터의 실제 인물 재사용 + CSS Fusion (추천·선택)**
2. 새 인물 생성
3. 포스터 자체 사용
4. 3D AI 그래픽 추가
5. 사용자 정의(직접 입력)

**결정 기록:** 응답을 기다리지 않고, 이미 제공한 포스터·문구·디자인 사양서에 가장 부합하는 추천안을 가정하여 진행했습니다.

## 이름 및 재사용 규칙
- `speaker-cutout.webp`: 사용자 제공 강사 사진에서 인물을 분리한 투명 WebP, 실제 모습 보존.
- `seminar-poster-og.jpg`: 제공 포스터에서 만든 공유용 이미지. 배포 후 OG 절대주소 교체 권장.
- `references/original-seminar-poster.png`: 원본 보관, 웹 서비스 폴더에 불필요하게 복제하지 않음.
- 웹 기본 경로는 `landing/assets/`입니다.

## 주의
- 강사 사진 사용 허가는 제공자가 확인해야 합니다.
- 헤어·옷 주위 투명 배경은 자동 분리 과정의 근사 결과로 일부 가장자리 흔적이 남을 수 있습니다.


## 실패 시나리오 및 대응
1. **가격과 접속 절차 미확인으로 신청을 망설임** → 신청폼 또는 주최 측의 확정 정보 확인 후 FAQ와 세부 안내를 업데이트합니다.
2. **사진·문구가 작은 화면에서 겹침** → 375px뿐 아니라 320px까지 화면 캡처와 넘침 검사를 반복합니다.
3. **신청폼 접근이나 링크 전달에 장애 발생** → 주최 측이 실제 모바일 기기에서 폼을 최종 확인하고 링크를 교체·안내합니다.
