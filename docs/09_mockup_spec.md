## 단계 시작 방향성 제안
1. **실제 HTML 렌더링을 화면 목업으로 저장 (추천·선택)**
2. 스케치형 와이어프레임
3. 원본 포스터 단순 리사이즈
4. 전체 이미지에 글자 고정
5. 사용자 정의(직접 입력)

**결정 기록:** 응답을 기다리지 않고, 이미 제공한 포스터·문구·디자인 사양서에 가장 부합하는 추천안을 가정하여 진행했습니다.

## 구성 및 검수 기준
- PC: 실제 강사 얼굴 우측 강조, 좌측 H1 → 일정 → CTA.
- 태블릿: 좌측 CTA와 우측 사진이 공존하되 수평 스크롤 없음.
- 모바일: 본문과 CTA를 먼저 제공하고 사진을 아래로 배치, 하단 고정 신청 버튼 제공.
- 세 이미지 모두 동일한 반응형 HTML의 캡처입니다. **독립적으로 승인한 사전 목업은 아니므로, Phase 12에서 '독립 목업과의 일치'는 객관 판정할 수 없습니다.**


## 실패 시나리오 및 대응
1. **가격과 접속 절차 미확인으로 신청을 망설임** → 신청폼 또는 주최 측의 확정 정보 확인 후 FAQ와 세부 안내를 업데이트합니다.
2. **사진·문구가 작은 화면에서 겹침** → 375px뿐 아니라 320px까지 화면 캡처와 넘침 검사를 반복합니다.
3. **신청폼 접근이나 링크 전달에 장애 발생** → 주최 측이 실제 모바일 기기에서 폼을 최종 확인하고 링크를 교체·안내합니다.
