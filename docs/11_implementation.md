## 단계 시작 방향성 제안
1. **정적 사이트 + Google Form 직접 연결 (추천·선택)**
2. 서버 폼 자체 구현
3. 웹프레임워크 기반
4. 페이지 이미지 하나로 배포
5. 사용자 정의(직접 입력)

**결정 기록:** 응답을 기다리지 않고, 이미 제공한 포스터·문구·디자인 사양서에 가장 부합하는 추천안을 가정하여 진행했습니다.

## 파일 구조
```text
landing/
  index.html     # 페이지 시맨틱 구조, 신청 링크 5곳, SEO
  styles.css     # PC/Tablet/Mobile 레이아웃 및 브랜드 토큰
  script.js      # 향후 클릭 분석 연결 지점(현재 개인정보 수집 없음)
  assets/
    speaker-cutout.webp
    seminar-poster-og.jpg
```
## 실제 기능
- 신청 링크: https://forms.gle/vKgXhViRCCGvM8Z98
- 링크 위치: 상단바 / 히어로 / 상세 카드 / 마지막 CTA / 모바일 고정. 전부 동일 URL.
- 내장 질문 펼치기: HTML details/summary.
- 키보드 포커스 및 스크린리더 대응, 사진 대체 텍스트.
- 외부 Analytics, 수집 폼, AI API 호출, 결제 서버 없음.

## 배포 방법
1. ZIP 안의 `landing/` 디렉터리 내용 전체를 Netlify Drop 또는 정적 호스팅 서비스에 올립니다.
2. 배포 주소가 정해지면 `<meta property="og:image">`에 절대 URL을 넣습니다.
3. 실제 스마트폰으로 신청 버튼을 눌러 폼 제출 과정과 접속 안내를 확인합니다.

## 확인 대상
- 구글폼은 방문자가 별도 창에서 작성합니다. 랜딩 코드만으로 구글폼 제출 상태를 수집하거나 ZOOM 접속 정보를 자동 발송하지 않습니다.


## 실패 시나리오 및 대응
1. **가격과 접속 절차 미확인으로 신청을 망설임** → 신청폼 또는 주최 측의 확정 정보 확인 후 FAQ와 세부 안내를 업데이트합니다.
2. **사진·문구가 작은 화면에서 겹침** → 375px뿐 아니라 320px까지 화면 캡처와 넘침 검사를 반복합니다.
3. **신청폼 접근이나 링크 전달에 장애 발생** → 주최 측이 실제 모바일 기기에서 폼을 최종 확인하고 링크를 교체·안내합니다.
