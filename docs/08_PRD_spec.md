## 타이포
- Pretendard 우선, Noto Sans KR 대체. 제목 -0.07em 가까운 자간 및 1.18~1.22행간, 본문 1.7~1.85.
- 데스크톱 제목 약 58px, 768에서 44px 전후, 375에서 36px.

## 그리드·반응형
- PC 1280: 최대 본문 1200px, 양옆 40px, 히어로 좌측 텍스트/우측 강사, 아래 2열/3열 분리.
- 태블릿 768: 24px 가터, 작은 2열 히어로, 본문 순차 1열.
- 모바일 375: 20px 가터, H1→설명→일정→CTA→사진, 하단 고정 CTA.
- 320px 보조 검수, 수평 오버플로 금지. 모바일 첫 CTA y약 512px(375 기준).

## 접근성·SEO·성능
- HTML `lang=ko`, 한 페이지 하나의 H1, 건너뛰기 링크, focus-visible, 버튼 대비, 이미지 대체 텍스트, details/summary 기본 키보드 동작, reduced-motion 지원.
- title/description/OpenGraph 제공; 게시용 사이트 절대주소 미설정으로 og:image는 배포 도메인 연결 후 재검증 필요.
- 소스 이미지 웹프 변환, 외부 폰트 및 프레임워크 없이 작동, 외부로 보내는 개인정보 없음.
