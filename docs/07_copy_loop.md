# Phase 7 · 카피 설계·검증 루프

> **프로젝트 마스터 카드** | 업종: 목회·AI 교육 세미나 | 목표: 구글폼 신청 전환 | 전달 메시지: GPT 프로젝트로 반복 설명과 자료 관리의 불편을 줄이는 방법을 배운다 | 확정: 이승주 목사, 2026-10-20(화) 20:00, ZOOM, 목회AI연구소 주최, Google Form 연결, 제공된 Soft Fusion 사양서 적용 | 현재 단계: Phase 7 · 카피 설계·검증 루프 | 열린 이슈: 참가비·접속 링크 전달 방식·세부 실습 여부·공식 로고 파일 [사용자 확인 필요]

## 단계 시작 방향성 제안
1. **문제 공감 → 정확한 세미나 내용 (추천·선택)**
2. 강사 타이틀 최우선
3. 도구 기능 목록 최우선
4. 감정형 호소 최우선
5. 사용자 정의(직접 입력)

**결정 기록:** 응답을 기다리지 않고, 이미 제공한 포스터·문구·디자인 사양서에 가장 부합하는 추천안을 가정하여 진행했습니다.

## 최초안: 검토 대상
- H1: 'GPT 프로젝트 활용법, 지금 배워 보세요.'
- Sub: '유용한 도구를 업무에 활용해 보세요.'
- CTA: '신청'
- 본문: 기능 소개 중심으로 구성.

## 1회차 검토(가상 역할평가, 실제 고객 실험 아님)
| 페르소나 | 헤더 | 서브 | CTA | 본문 | 핵심 평가 이유 |
|---|---:|---:|---:|---:|---|
| 긍정형 | 3 | 3 | 3 | 3 | 범위는 알지만 얻는 것이 추상적 |
| 부정형 | 2 | 2 | 3 | 2 | 일반적인 AI 홍보와 차별 부족 |
| 거부형 | 2 | 2 | 3 | 2 | 내 문제와 관계가 없음 |
| 신청형 | 3 | 3 | 3 | 3 | 날짜·진행 정보가 전면에 없음 |
| 관망형 | 2 | 3 | 3 | 2 | 비교 판단에 필요한 내용이 없음 |

## 수정 1회
- H1을 'GPT, 매번 처음부터 설명하고 계신가요?'로 변경.
- 정확한 세미나명 '이승주 목사님의 GPT 프로젝트 활용방법' 별도 표기.
- Sub를 '같은 질문과 설명을 반복했다면, 이제 GPT 프로젝트를 알아볼 때입니다.'로 수정.
- 본문에 자료/대화 관리, 목회·실제 업무 적용 명시.
- CTA를 '지금 바로 신청하기'로 수정하고 날짜·ZOOM을 바로 인접 배치.

## 통과 판정
- 조건: 모든 페르소나가 모든 요소 4점 이상이고, 거부형 핵심 이탈 원인이 해결되어야 합니다.
- **현재 상태: 미통과.** 비판형·관망형 본문 점수 3점. 실습 범위, 참가비, 접속 안내에 사용자 확인 필요.
- 3~5회차를 억지로 진행해 점수를 올리지 않고 확인 정보를 기다리는 것이 정직합니다.
- 예상 효율: **중간(시뮬레이션 가설)**. 공감/CTA는 개선됐지만 결제·접속 정보를 모르는 장벽이 남습니다. 실제 전환율 측정값이 아닙니다.


## 실패 시나리오 및 대응
1. **가격과 접속 절차 미확인으로 신청을 망설임** → 신청폼 또는 주최 측의 확정 정보 확인 후 FAQ와 세부 안내를 업데이트합니다.

3. **신청폼 접근이나 링크 전달에 장애 발생** → 주최 측이 실제 모바일 기기에서 폼을 최종 확인하고 링크를 교체·안내합니다.
